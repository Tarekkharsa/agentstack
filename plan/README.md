# plan/

Working documents and evidence captures that sit **behind** entries in
`TODO.md` — review boards, scope notes, claim audits, captured screens. They
exist so a queue entry can stay one paragraph while the measurement it rests on
is still readable. Cite them from the entry; do not read them as instructions.

`plan/absorbed/` is superseded material. Whatever it said has been absorbed
into a live document or overtaken by a decision, and it is kept only so a
citation does not dangle.

Neither this directory nor anything in it is an authority:

- **`TODO.md` is the only work queue.** Where a document here disagrees with
  it, the queue wins.
- **`STRATEGY.md` is the only strategy.** Nothing here reopens it.
- `docs/ARCHITECTURE.md` and `docs/ENFORCEMENT.md` say what the code does and
  enforces; a plan document describing enforcement is a draft, not a claim.
